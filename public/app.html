связь

связь — это социальная сеть для обмена публикациями, медиафайлами и общения. Пользователи могут публиковать фотографии, видео и музыку, комментировать записи друг друга, ставить лайки и находить новых людей по интересам.

Назначение приложения

Приложение предназначено для создания и просмотра пользовательского контента: текстовых записей, изображений, видео и аудио. Основные функции:

  • Публикация постов с медиафайлами (до 10 МБ каждый).
  • Лента публикаций с фильтрами «Для вас», «Свежее», «Топ».
  • Комментарии к публикациям.
  • Реакции (лайки) на публикации.
  • Профиль пользователя с аватаром, именем и юзернеймом.
  • Аутентификация через Google OAuth.

Использование Google API

Приложение использует Google OAuth 2.0 исключительно для аутентификации пользователей. При входе через Google мы получаем:

  • Email — для идентификации аккаунта.
  • Имя и аватар профиля — для отображения в интерфейсе.

Мы не запрашиваем доступ к Gmail, Google Drive, Google Calendar или другим сервисам Google.

Наше приложение не использует Google API для создания или распространения несогласованных интимных изображений (NCII), в том числе сгенерированных искусственным интеллектом (дипфейков).
